一个独立助手：在 B 站页面提取，或把已有 JSON 自动转成文字。

01 / 视频页直接下载

把这个按钮拖到书签栏

B 站字幕转 TXT
  1. 把绿色按钮拖到浏览器书签栏，只需安装一次。
  2. 打开已登录的 B 站 BV / av 视频页，点击这个书签。
  3. 助手获取字幕 JSON 后自动生成 TXT 并下载；多轨字幕会先让你选语言。

书签包含完整程序，安装后不需要启动本地服务。支持当前分 P，以及直接打开的 B 站字幕 JSON 页面。旧版书签需要替换成新版。

无法拖动？手动安装书签

新建一个浏览器书签，名称填“B 站字幕转 TXT”，网址填下方完整代码。不要直接把代码粘贴进地址栏。

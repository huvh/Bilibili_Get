# B 站字幕转 TXT 独立助手

下载独立 ZIP 包并解压后，双击 `B站字幕转TXT助手.html`。
在源码项目中，双击 `helper/dist/B站字幕转TXT助手.html`，或项目根目录的 `打开独立字幕助手.cmd`。
这是单文件离线页面，不需要 Python、本地服务、SnapAny 或浏览器扩展。
页面顶部可切换到本地工作台的五项功能；其他工作台页面需要本地服务正在运行。

## 视频页直接获取 TXT

1. 把页面中的 **B 站字幕转 TXT** 按钮拖到 Chrome / Edge 的书签栏。
2. 打开已登录的 B 站 BV / av 视频页，点击该书签。
3. 助手获取字幕 JSON 后，在内存中自动转成 TXT 并触发下载；不需要手动保存或重新导入 JSON。
4. 单轨字幕直接处理；多轨先选语言。支持当前分 P，以及直接打开的 B 站字幕 CDN JSON 页面。
5. 浏览器未自动下载时，点面板里的“再次下载 TXT”。

**已经装过旧版书签，需要删掉或替换旧版，再拖入新版按钮。** 旧版书签把程序存在书签中，无法随项目文件自动更新。
无法拖动时，使用页面的“复制书签代码”，新建书签，将代码填入“网址”字段。

## 已有 JSON 自动转换

在独立页面选择或拖放 JSON 文件，立即转换并自动下载同名 TXT。
支持原生 BCC `body` 数组，以及旧助手的 `{title, language_tag, document}` 包装 JSON。
TXT 无时间戳、逐句换行、保留重复句，不改写内容；UTF-8 BOM 可供 Windows 记事本识别中文。
转换完全在浏览器中完成，不上传文件。

## 代码与验证

- `subtitle-core.mjs`：纯转换、文件名和字幕 URL 校验。
- `bookmarklet-runner.js`：B 站请求、语言选择、自动 TXT 下载及错误提示。
- `install.template.html`：安装入口与离线 JSON 自动转换。
- `build.py`：生成单文件页面，并更新工作台的 `/helper` 和旧助手入口。
- `test-helper.mjs`：转换边界及书签请求/下载流程测试。

修改后执行 `python helper/build.py`；验证执行 `node --test helper/test-helper.mjs`。
测试使用合成字幕和模拟网络，覆盖 997 条字幕转换、单轨 / 多轨书签下载、权限分支和地址校验。
用户登录态下的真实字幕获取仍取决于 B 站权限、网络和页面策略。
